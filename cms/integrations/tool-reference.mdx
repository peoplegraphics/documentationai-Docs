The PanelWave MCP server offers **81 tools**. An assistant only sees the tools your connection's permissions allow; your team role and plan limits still apply. Tools marked **Asks first** remove or publish something that is hard to undo, so the assistant asks you to confirm before it runs them. Tools marked **asks first when risky** ask only for their risky variants, such as publishing to production.

## Permissions

| Permission | Granted by default | Lets the assistant |
|------------|--------------------|--------------------|
| `works:read` | Yes | Read your works: structure, panels, characters, variables, graph, validation reports and translations. |
| `works:write` | Yes | Create, change, reorder and delete works, chapters, pages, panels, balloons, hotspots, characters, variables and graph edges. |
| `assets:read` | Yes | List your uploaded images, videos and audio and view their thumbnails. |
| `assets:write` | Yes | Upload, replace, organise and delete assets and attach artwork to panels. |
| `localization:write` | Yes | Add languages, edit translations and start machine translation or text-to-speech. |
| `publish` | Yes | Run validation fixes, publish previews and releases, and roll back. |
| `team:read` | Yes | See your teams, plan limits and credit balance. |
| `analytics:read` | No | Read reader analytics of your works. |

## Tools on your computer

With the [local bridge](/cms/integrations/local-bridge) the assistant also gets three tools that work on files in the folders you allowed: `pw_local_list_files`, `pw_local_read_text` and `pw_local_upload_files`. Nothing outside those folders is readable.
